This repo contains code for a simple smart home device that calls public transit and weather APIs and displays them on a small LED screen.

Always follow these guidelines when writing code in this repo:

- Do not start writing code unless the user is explicitly asking you to.
- Do not add unecessary bells and whistles. Only write the code that you are asked to write.
- Do not narrate your process, or overexplain things. Avoid jargon unless strictly necessary.
- Avoid going down rabbit holes - if you are confused about something, it is much better to ask the user for clarification rather than burning cycles trying to make meaning where none exists.
- Use `uv` to manage and run python, never pip.
